# Baseline

**Подход:** обработка каждого кадра видео независимо (frame-by-frame pipeline).
Цель baseline — получить простую, воспроизводимую систему, которая извлекает из кадра **объекты, их координаты и текстовое описание**, после чего объединяет эту информацию в единую структуру.

---

# Pipeline

## 1. Входные данные

На вход системы поступает **один кадр видео**.

Формат входа:

```
frame: H x W x 3 (RGB)
timestamp (optional)
camera_id (optional)
```

На этом этапе **никакая временная информация не используется** — каждый кадр обрабатывается независимо.

---

# 2. Open-set Object Detection

Кадр пропускается через **open-set detector**, задача которого — обнаружить **все объекты сцены**, включая те, которые не входят в фиксированный набор классов.

Результат детектора:

Каждый объект описывается:

* bounding box (bbox) в координатах изображения
* confidence score

На этом этапе **классы объектов не фиксированы** — детектор выполняет только локализацию.

Возможные реализации:

* open-vocabulary detectors
* grounding-based detectors
* DETR-based модели

---

# 3. Обработка каждого обнаруженного объекта

Для каждого `bbox` выполняются два независимых процесса.

---

## 3.1 Оценка координат объекта

Используя **гомографию сцены**, координаты объекта переводятся из координат изображения в координаты сцены.

### Вход

```
середина нижнего ребра bounding box'а (u, v)
homography matrix H
```

### Преобразование

```
[X, Y, 1]^T ~ H * [u, v, 1]^T
```

### Результат

```
object_position = {
    x: float,
    y: float,
    z: optional
}
```

На практике:

* `z` может отсутствовать
* используется **плоская модель сцены (ground plane)**

Этот этап требует **калибровки камеры**.

---

## 3.2 Текстовое описание объекта

Из bounding box извлекается **кроп изображения**:

```
object_crop = frame[y1:y2, x1:x2]
```

Кроп передаётся в **vision-language модель**, которая генерирует текстовое описание.

Пример результата:

```
"red car"
"person with backpack"
"metal pole"
"construction barrier"
```

Модель может выполнять:

* captioning
* open-vocabulary classification
* object description

Возможные модели:

* vision-language captioning models
* CLIP-like модели
* instruction-following VLM

---

# 4. Агрегация информации об объектах

Информация обо всех объектах объединяется в единый список.

Формат итогового представления:

```
objects = [
    {
        bbox_2d: [x1, y1, x2, y2],
        position_3d: [X, Y, Z],
        description: "text description",
        score: float
    },
    ...
]
```

В результате каждый объект имеет:

* **2D координаты** (bounding box)
* **координаты в сцене**
* **текстовую интерпретацию**

---

# Выход системы

Результат обработки одного кадра:

```
FrameResult {
    timestamp
    objects[]
}
```

где каждый объект содержит:

* bbox
* координаты объекта
* текстовое описание

---

# Ограничения baseline

Этот baseline **не использует временную информацию**.

Следовательно:

* нет трекинга объектов
* нет агрегации между кадрами
* возможны дублирования
* возможна нестабильность описаний

Тем не менее, такой подход:

* прост в реализации
* легко дебажится
* подходит как первая версия системы

# Summary

Baseline pipeline:

```
Frame
  ↓
Open-set Detector
  ↓
Bounding Boxes
  ↓
├─ Coordinate Estimation (Homography)
└─ Vision-Language Description
  ↓
Object Aggregation
  ↓
Structured Scene Representation
```

Этот baseline формирует **минимальную архитектуру**, на основе которой можно постепенно строить более сложную систему.
